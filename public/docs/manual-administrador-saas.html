1. Acceso al Panel de Administracion

Requisitos

Para acceder al panel de administracion SaaS, el usuario debe cumplir:

  • Tener el rol saas_admin asignado
  • No pertenecer a ninguna organizacion (organization_id debe ser nulo)
  • Tener credenciales activas (email + password)

URL de Acceso

El panel de administracion se accede desde:

https://admin.chatme.com.mx/panel

Ingresa con tu email y contrasena. El sistema validara automaticamente que tienes el rol adecuado.

Nota: Si un usuario tiene organization_id asignado, sera redirigido al dashboard de la aplicacion aunque tenga el rol saas_admin.

Navegacion

El panel cuenta con una barra lateral izquierda con los siguientes modulos:

  • Dashboard — Metricas generales de la plataforma
  • Organizaciones — CRUD de clientes
  • Usuarios — Gestion de usuarios de toda la plataforma
  • Planes — Configuracion de planes y features
  • Suscripciones — Gestion de suscripciones activas
  • Uso — Monitoreo de consumo por organizacion
  • Alertas — Alertas del sistema
  • Formularios — Templates de formularios de webchat
  • Mantenimiento — Modo mantenimiento por organizacion
  • Horizon — Monitoreo de colas Redis (enlace externo)

3. Gestion de Organizaciones

Las organizaciones son los clientes de la plataforma. Cada organizacion es un tenant aislado con sus propios usuarios, conversaciones, negocios y configuraciones.

3.1 Listar Organizaciones

La vista principal muestra todas las organizaciones con filtros:

  • Busqueda: Por nombre o slug
  • Filtro de estado: Activo, Suspendido, Trial, o Todos
  • Paginacion: 20 organizaciones por pagina

3.2 Crear Organizacion

1
Haz clic en "Nueva Organizacion" en la esquina superior derecha.
2
Completa el formulario:
  • Nombre: Nombre de la empresa cliente (obligatorio)
  • Estado: Selecciona "active" o "trial"
El slug se genera automaticamente del nombre.
3
Haz clic en "Crear". La organizacion aparecera en el listado.

3.3 Ver Detalle

Al hacer clic en una organizacion se muestra:

  • Nombre y subdominio (slug.chatme.com.mx)
  • Estado actual
  • Cantidad de usuarios y sucursales
  • Plan de suscripcion actual
  • Tabla de todos los usuarios de la organizacion

3.4 Suspender / Activar

Desde el detalle de la organizacion:

  • Suspender: Bloquea el acceso de todos los usuarios de la organizacion. Muestra confirmacion antes de ejecutar.
  • Activar: Restaura el acceso. Solo disponible para organizaciones suspendidas.
Importante: Al suspender una organizacion, TODOS sus usuarios perderan acceso inmediatamente. Las conversaciones y datos se mantienen intactos.

3.5 Editar

Se puede modificar el nombre. El slug solo se puede cambiar si la organizacion no tiene usuarios, sucursales ni suscripciones.

3.6 Eliminar

Solo se puede eliminar una organizacion que no tenga usuarios. Esta accion es irreversible.

Precaucion: Antes de eliminar, asegurate de reasignar o eliminar todos los usuarios de la organizacion.

4. Gestion de Usuarios

4.1 Listar Usuarios

Muestra todos los usuarios de la plataforma con filtros:

  • Busqueda: Por nombre o email
  • Filtro por rol: Todos los roles disponibles
  • Filtro por organizacion: Dropdown de todas las organizaciones

4.2 Crear Usuario

CampoObligatorioDescripcion
NombreSiNombre completo del usuario
EmailSiEmail unico en toda la plataforma
ContrasenaSiDebe cumplir reglas de seguridad de Laravel
OrganizacionNoAsignar a una organizacion o dejarlo como usuario de plataforma
RolSiorg_admin, supervisor, agent, o saas_admin
Usuarios SaaS Admin: Para crear otro administrador de plataforma, deja la organizacion vacia y asigna el rol "saas_admin".

4.3 Editar Usuario

Se pueden modificar todos los campos. La contrasena es opcional (dejar vacia para mantener la actual). Se puede activar/desactivar el usuario con el checkbox "Activo".

4.4 Eliminar Usuario

No puedes eliminarte a ti mismo. Se requiere confirmacion.

5.1 Estructura de Planes

Cada plan define:

  • Precio mensual y anual (en centavos MXN)
  • Dias de prueba
  • Valores de features (limites y funciones habilitadas)

5.3 Crear / Editar Plan

Al crear o editar un plan, se configuran los valores de cada feature. Los tipos de feature son:

  • Booleanos: true/false (ej: webchat_enabled, reports_enabled)
  • Limites: numero o "unlimited" (ej: max_agents, max_channels)

6. Suscripciones

6.1 Estados de Suscripcion

EstadoDescripcionAcceso
activeSuscripcion vigenteCompleto
trialingEn periodo de pruebaCompleto
canceledCancelada con periodo de gracia (7 dias)Solo lectura despues del periodo
past_duePago vencidoSolo lectura

6.2 Crear Suscripcion Manual

1
Selecciona la organizacion (solo organizaciones activas)
2
Selecciona el plan (muestra precios)
3
Elige estado: "active" o "trialing"
4
Elige ciclo: mensual o anual

El sistema calcula automaticamente:

  • Fecha de inicio: Ahora
  • Fecha de fin: +1 mes (mensual) o +1 ano (anual)
  • Fin de trial: +14 dias (si estado es trialing)

6.3 Gestionar Suscripcion

Desde el detalle puedes cambiar plan, estado y ciclo de facturacion. Si hay integracion con Stripe, se muestra el ID de suscripcion de Stripe.

8.3 Alertas Automaticas

El sistema genera alertas automaticamente cuando:

  • Una organizacion supera el 90% de uso de un feature
  • Hay jobs fallidos en la cola
  • Un deal lleva demasiado tiempo en una etapa (SLA)

8.4 Resolver Alerta

Al resolver una alerta, se registra quien la resolvio y cuando. La alerta se desactiva automaticamente.

9. Formularios de Canal (Webchat)

Los formularios se asignan a canales de tipo Webchat para recopilar informacion del visitante antes de iniciar una conversacion.

9.1 Templates Disponibles

  • contacto_basico: Nombre, email, telefono
  • muebleria: Datos de contacto + tipo de mueble
  • agencia_viajes: Datos + destino, fechas, presupuesto

9.2 Asignar Formulario

Solo se puede asignar un formulario a canales Webchat que no tengan uno ya asignado. Selecciona el canal y el template, y el sistema creara el formulario con el esquema JSON correspondiente.

9.3 Vista de Formulario

Muestra el esquema JSON completo, el conteo de campos, el estado y la organizacion/canal asociados.

10. Modo Mantenimiento

Permite poner organizaciones individuales en modo mantenimiento sin afectar a las demas.

Como funciona

  • Al activar el modo mantenimiento, los usuarios de esa organizacion veran un mensaje de mantenimiento al intentar acceder
  • Los datos no se modifican
  • Las APIs y webhooks siguen funcionando normalmente
  • Se registra la fecha/hora del cambio

Activar / Desactivar

Desde la tabla de mantenimiento, haz clic en el boton "Activar" o "Desactivar" junto a la organizacion deseada.

13. Detalle de Planes por Defecto

Starter - $499/mes

Ideal para negocios pequenos que inician con atencion digital.

  • 3 agentes, 1 canal, 100 conversaciones/mes, 500 mensajes/mes
  • 100 contactos, 1 marca, 20 articulos KB
  • WhatsApp y Webchat habilitados
  • Sin campanas, drip, automaciones, reportes ni IA
  • 14 dias de prueba gratis

Professional - $999/mes

Para empresas en crecimiento que necesitan automatizacion y reportes.

  • 10 agentes, 5 canales, 1,000 conversaciones/mes, 10,000 mensajes/mes
  • 5,000 contactos, 5 marcas, 200 articulos KB
  • Todas las funciones habilitadas (campanas, drip, automaciones, reportes, IA)
  • SLA tracking, API access, custom branding
  • 14 dias de prueba gratis

Enterprise - $2,499/mes

Para grandes operaciones con necesidades ilimitadas.

  • Todo ilimitado
  • Todas las funciones habilitadas
  • Sin periodo de prueba (acceso inmediato)

14. Resolucion de Problemas

Problema: Usuario no puede acceder

CausaSolucion
Organizacion suspendidaActivar la organizacion desde el panel admin
Usuario inactivoActivar el usuario desde Usuarios > Editar
Modo mantenimiento activoDesactivar desde Mantenimiento
Sin suscripcionCrear suscripcion manual
Suscripcion expiradaRenovar o cambiar plan

Problema: Feature no disponible para el cliente

  • Verificar que el plan del cliente incluya el feature (Planes > Ver plan)
  • Verificar que la suscripcion este activa (no canceled ni past_due)
  • Si es un limite, verificar el uso en Monitoreo de Uso

Problema: Mensajes de WhatsApp no llegan

  • Verificar que el canal este activo en la configuracion del cliente
  • Revisar Horizon para jobs fallidos en la cola "critical"
  • Verificar credenciales del canal (token de Meta API)

Problema: WebSocket no funciona

  • Verificar que Laravel Reverb este corriendo en el servidor
  • Verificar la configuracion de REVERB_* en .env
  • Revisar los allowed_origins en la configuracion de Reverb
