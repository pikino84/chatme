1. Primeros Pasos

1.1 Acceso a la Plataforma

Accede a ChatMe desde tu navegador en:

https://app.chatme.com.mx

1.2 Iniciar Sesion

1
Ingresa tu email y contrasena
2
Si tienes autenticacion de dos factores (2FA) activada, ingresa el codigo de tu aplicacion autenticadora
3
Seras redirigido al Dashboard

1.3 Navegacion

La barra lateral izquierda contiene los modulos principales:

ModuloDescripcionRoles
InicioDashboard con accesos rapidosTodos
BandejaConversaciones con clientesTodos
NegociosPipeline de ventas (Kanban)Todos
CampanasEnvios masivosAdmin, Supervisor
ContactosDirectorio de contactosTodos
Base de ConocimientoArticulos de ayudaTodos
ReportesAnalitica y metricasAdmin, Supervisor

La seccion Admin (solo visible para administradores) incluye:

  • Canales — Configurar WhatsApp, Webchat, etc.
  • Facturacion — Plan y suscripcion
  • Configuracion — Datos de la organizacion
  • Equipo — Gestion de miembros
  • Pipelines — Configurar embudos de venta
  • Etiquetas — Crear etiquetas para negocios

1.4 Perfil y Seguridad

Desde tu foto de perfil (esquina inferior izquierda) puedes:

  • Editar tu nombre y email
  • Cambiar contrasena
  • Activar/desactivar autenticacion de dos factores (2FA)
  • Cerrar sesiones en otros dispositivos
  • Cerrar sesion

2. Dashboard

El Dashboard muestra un saludo personalizado con el nombre de tu organizacion y tarjetas de acceso rapido a los modulos principales: Bandeja, Negocios, Base de Conocimiento, Facturacion, y Configuracion.

3. Bandeja de Entrada (Inbox)

La Bandeja es el centro de operaciones donde gestionas todas las conversaciones con tus clientes, sin importar el canal (WhatsApp, Webchat, etc.).

3.1 Lista de Conversaciones

En el panel izquierdo veras todas las conversaciones con:

  • Nombre del contacto o identificador
  • Vista previa del ultimo mensaje
  • Tiempo desde el ultimo mensaje
  • Estado: Abierta Pendiente Cerrada
  • Canal: WhatsApp, Webchat, etc.
  • Marca (si aplica)
  • Agente asignado

Filtros Disponibles

  • Buscar: Por nombre o identificador del contacto
  • Estado: Todos, Abiertas, Pendientes, Cerradas
  • Canal: Filtrar por canal especifico
  • Marca: Filtrar por marca
  • Agente: Filtrar por agente asignado

3.2 Vista de Conversacion

Al seleccionar una conversacion, veras tres areas:

Panel Izquierdo - Metadata

  • Nombre del contacto, identificador, canal
  • Estado, prioridad, agente asignado
  • Fecha de creacion y metadatos adicionales

Panel Central - Hilo de Mensajes

  • Mensajes entrantes (del cliente): alineados a la izquierda
  • Mensajes salientes (tuyos): alineados a la derecha, fondo indigo
  • Notas internas: fondo amarillo, solo visibles para el equipo
  • Cada mensaje muestra hora y nombre del agente

Enviar Mensaje

  • Escribe en el area de texto inferior
  • Presiona Enter para enviar o Shift+Enter para nueva linea
  • Haz clic en "Nota" para enviar una nota interna (no visible para el cliente)

3.3 Acciones sobre Conversaciones

AccionDescripcionRol Minimo
CerrarMarca la conversacion como resueltaAgent
ReabrirReabre una conversacion cerradaAgent
AsignarAsignar a un agente del equipoSupervisor
TransferirTransferir a otro agente (con razon opcional)Supervisor

3.4 Mensajes en Tiempo Real

Los mensajes nuevos aparecen automaticamente gracias a WebSocket. No necesitas recargar la pagina. Si la conexion WebSocket no esta disponible, el sistema hace polling cada 5 segundos como respaldo.

Consejo: Las notas internas son excelentes para documentar informacion importante de la conversacion sin que el cliente las vea.

4. CRM - Negocios (Deals)

El modulo de Negocios te permite gestionar oportunidades de venta usando un tablero Kanban visual.

4.1 Tablero Kanban

El tablero muestra columnas para cada etapa del pipeline seleccionado. Los negocios aparecen como tarjetas dentro de cada columna.

Selector de Pipeline

Si tienes mas de un pipeline, usa el dropdown en la parte superior para cambiar entre ellos.

Tarjetas de Negocio

Cada tarjeta muestra:

  • Nombre del contacto
  • Valor del negocio (ej: $10,000.00 MXN)
  • Agente asignado
  • Etiquetas (badges de colores)
  • Tiempo en la etapa actual

4.2 Crear Negocio

1
Haz clic en "+ Nuevo Negocio"
2
Completa el formulario:
  • Nombre del contacto (obligatorio)
  • Email y telefono (opcional)
  • Valor del negocio
  • Fecha de cierre esperada
  • Agente asignado
3
El negocio se crea en la primera etapa del pipeline

4.3 Detalle del Negocio (Drawer)

Al hacer clic en una tarjeta, se abre un panel lateral con toda la informacion:

Informacion del Contacto

Nombre, email y telefono del contacto.

Informacion del Negocio

Pipeline, etapa actual (con color), valor, estado, fecha de cierre esperada y agente asignado.

Etiquetas

Muestra las etiquetas asignadas. Puedes agregar o quitar etiquetas usando los checkboxes y presionando "Actualizar Etiquetas".

Mover Etapa

Selecciona una nueva etapa del dropdown y haz clic en "Mover". El negocio se mueve a la nueva columna del tablero.

Reasignar

Cambia el agente responsable del negocio.

Archivos Adjuntos

Sube documentos relacionados al negocio (contratos, cotizaciones, etc.). Maximo 10 MB por archivo. Puedes ver y descargar archivos existentes o eliminarlos.

Notas

Agrega notas sobre el negocio. Cada nota muestra quien la escribio y cuando.

Comisiones

Solo Admin

Gestiona comisiones para los agentes:

  • Selecciona el agente y el porcentaje de comision
  • El monto se calcula automaticamente del valor del negocio
  • Flujo de estados: Pendiente → Aprobada → Pagada
  • Tambien se puede cancelar: Cancelada

Historial de Etapas

Linea de tiempo con todos los movimientos del negocio entre etapas.

Conversacion Vinculada

Si el negocio se creo desde una conversacion, se muestra un enlace directo a ella.

5. Configurar Pipelines

Solo Admin

Los pipelines definen las etapas por las que pasan tus negocios. Puedes tener multiples pipelines (ej: Ventas, Postventa, Renovaciones).

5.1 Lista de Pipelines

Muestra todos los pipelines con:

  • Nombre y badge Predeterminado
  • Cantidad de etapas y negocios
  • Vista previa visual de las etapas (con colores y flechas)

5.2 Crear Pipeline

1
Haz clic en "+ Nuevo Pipeline"
2
Ingresa el nombre del pipeline (ej: "Ventas Principal")
3
Configura las etapas:
  • Nombre: Nombre de la etapa (ej: "Prospecto", "Negociacion")
  • Color: Color identificador de la etapa
  • Max horas: Duracion maxima esperada en esta etapa (SLA)
  • Ganado: Marca si esta etapa indica cierre exitoso
  • Perdido: Marca si esta etapa indica cierre fallido
4
Arrastra las etapas para reordenarlas
Consejo: Todo pipeline necesita al menos una etapa marcada como "Ganado" y una como "Perdido" para cerrar negocios correctamente.

5.3 Pipeline Predeterminado

El pipeline predeterminado es el que se usa al crear nuevos negocios. Haz clic en "Hacer predeterminado" junto al pipeline que desees.

5.4 Eliminar Pipeline

Solo se pueden eliminar pipelines que no tengan negocios asociados. Si tiene negocios, primero debes moverlos a otro pipeline.

6. Etiquetas

Solo Admin

Las etiquetas permiten clasificar y filtrar negocios. Cada etiqueta tiene un nombre y un color.

6.1 Crear Etiqueta

En la parte superior de la pagina, ingresa el nombre, selecciona un color y haz clic en "Crear".

6.2 Editar Etiqueta

Haz clic en "Editar" junto a la etiqueta. Se abrira un formulario inline donde puedes cambiar nombre y color.

6.3 Eliminar Etiqueta

Al eliminar una etiqueta, se desasocia automaticamente de todos los negocios. Los negocios no se ven afectados.

6.4 Asignar Etiquetas a Negocios

Desde el detalle de un negocio (drawer), usa los checkboxes en la seccion "Etiquetas" para asignar o quitar etiquetas.

7. Contactos

El modulo de Contactos es tu directorio centralizado de clientes y prospectos.

7.1 Buscar Contactos

Usa la barra de busqueda para encontrar contactos por nombre, email o telefono.

7.2 Crear Contacto

CampoObligatorioDescripcion
NombreSiNombre completo del contacto
EmailNoCorreo electronico
TelefonoNoNumero de telefono (formato internacional para WhatsApp)
EmpresaNoNombre de la empresa del contacto
NotasNoNotas adicionales

7.3 Perfil del Contacto

Al ver un contacto, se muestra:

  • Informacion de contacto: Todos los datos registrados
  • Conversaciones: Historial de conversaciones con el contacto
  • Negocios: Deals asociados con valor y estado

7.4 Importar desde CSV

Solo Admin
1
Haz clic en "Importar CSV"
2
Prepara tu archivo CSV con las columnas: name (obligatorio), email, phone, company, notes. La primera fila debe ser el encabezado.
3
Selecciona el archivo y haz clic en "Importar"
Limite: La cantidad maxima de contactos depende de tu plan. Starter: 100, Professional: 5,000, Enterprise: Ilimitado.

8. Campanas de Difusion

Solo Admin

Disponible en planes Professional y Enterprise

Las campanas permiten enviar mensajes masivos a multiples contactos a traves de un canal.

8.1 Crear Campana

1
Haz clic en "+ Nueva Campana"
2
Completa:
  • Nombre: Nombre identificador de la campana
  • Canal: Canal de envio (WhatsApp, Webchat, etc.)
  • Mensaje: Template del mensaje a enviar
3
Agrega destinatarios: Selecciona contactos que tengan telefono registrado
4
Haz clic en "Enviar Ahora" cuando estes listo

8.2 Estados de Campana

EstadoDescripcion
BorradorEn preparacion, aun no enviada
ProgramadaProgramada para envio futuro
EnviandoEn proceso de envio
CompletadaTodos los mensajes enviados
CanceladaEnvio cancelado

8.3 Metricas de Campana

Cada campana muestra: total destinatarios, enviados exitosamente, fallidos y tasa de envio.

9. Secuencias Drip

Solo Admin

Disponible en planes Professional y Enterprise

Las secuencias Drip envian mensajes automaticos a contactos en intervalos programados.

9.1 Crear Secuencia

1
Crea la secuencia con un nombre y trigger (evento que la activa)
2
Agrega pasos:
  • Espera: Minutos de retraso antes de enviar
  • Canal: WhatsApp o Webchat
  • Mensaje: Template del mensaje
3
Activa la secuencia cuando estes listo

9.2 Inscribir Contactos

Desde el detalle de la secuencia, puedes inscribir contactos manualmente ingresando su ID. Los contactos inscritos avanzaran automaticamente por los pasos segun los tiempos configurados.

9.3 Estados de Inscripcion

  • Activa — El contacto esta recibiendo mensajes
  • Completada — Todos los pasos fueron ejecutados
  • Cancelada — La inscripcion fue cancelada manualmente

10. Automatizaciones

Solo Admin

Disponible en planes Professional y Enterprise

Las automatizaciones ejecutan acciones automaticas basadas en eventos del sistema.

10.1 Tipos de Automatizacion

TipoDescripcionConfiguracion
Auto-asignacion Asigna conversaciones nuevas automaticamente a un agente Metodo: Round Robin (turno) o Least Busy (menos ocupado)
Auto-respuesta Envia un mensaje automatico cuando llega una conversacion nueva Template del mensaje automatico
Alerta de inactividad Genera alerta cuando una conversacion lleva mucho tiempo sin respuesta Umbral en minutos (minimo 5, por defecto 30)

10.2 Crear Regla

1
Haz clic en "Nueva Regla"
2
Selecciona el tipo de automatizacion
3
Opcionalmente, selecciona un canal especifico o deja "Todos"
4
Configura los parametros especificos del tipo

10.3 Activar / Desactivar

Desde la lista de automatizaciones, haz clic en el badge de estado para activar o desactivar una regla sin eliminarla.

11. Base de Conocimiento

La Base de Conocimiento almacena articulos de ayuda que la IA puede usar para responder preguntas de tus clientes automaticamente.

11.1 Categorias

Organiza tus articulos en categorias. Cada categoria tiene nombre, descripcion, posicion (orden) y estado.

11.2 Crear Articulo

CampoDescripcion
TituloTitulo descriptivo del articulo
CategoriaCategoria a la que pertenece
MarcaMarca asociada o "Global" (visible para todas las marcas)
ContenidoContenido completo del articulo
Prioridad0-100, mayor prioridad = mas relevante en busquedas
VisibilidadEn que canales se muestra (Webchat, WhatsApp, Instagram, Facebook)

11.3 Flujo de Publicacion

  • Borrador → El articulo no es visible ni se usa en busquedas
  • Publicado → Visible y disponible para la IA
  • Archivado → Oculto pero no eliminado

11.4 Versionamiento

Cada edicion de un articulo crea una nueva version. Puedes ver el historial de versiones en la vista de detalle del articulo.

Consejo: Escribe articulos claros y detallados. La IA los usa para generar respuestas, asi que entre mejor sea el contenido, mejor sera la calidad de las respuestas automaticas.

Disponible en planes Professional y Enterprise

12.1 Periodos

12.2 Metricas Principales

MetricaDescripcion

MensajesTotal, entrantes y salientes
NegociosTotal, ganados y perdidos

  • Volumen de Mensajes: Grafica de barras con mensajes diarios
  • Conversaciones por Canal: Grafica de dona (WhatsApp vs Webchat, etc.)
  • Estado de Negocios: Grafica de dona (abiertos, ganados, perdidos)

Tabla con metricas por agente: conversaciones atendidas, cerradas y tiempo promedio de resolucion.

12.5 Exportar CSV

Haz clic en "Exportar CSV" para descargar un reporte completo con secciones de conversaciones, mensajes, deals, agentes y SLA.

13. Marcas

Solo Admin

Si tu negocio maneja multiples marcas, puedes crear una marca por cada una. Las marcas se asocian a canales, conversaciones y articulos de KB.

13.1 Crear Marca

CampoDescripcion
NombreNombre de la marca (ej: "Rosanegra Polanco")
DescripcionBreve descripcion
ColorColor visual para identificar la marca
Contexto IAInstrucciones especificas para que la IA responda en nombre de esta marca

13.2 Vista de Marca

Muestra estadisticas: sucursales, canales, conversaciones y articulos KB asociados.

Contexto IA: Escribe informacion como tipo de negocio, horarios, direccion, politicas, tono de comunicacion. La IA usara esto para personalizar sus respuestas.

14. Configuracion

Solo Admin

14.1 Organizacion

  • Nombre: Nombre de tu empresa
  • Zona Horaria: Importante para reportes y SLA
  • Logo: Logo de la empresa (max 1 MB, JPG/PNG/SVG)

14.2 Equipo

Gestiona los miembros de tu equipo:

  • Ver miembros: Nombre, email, rol y estado de cada miembro
  • Cambiar rol: Selecciona un nuevo rol del dropdown y haz clic en "Asignar"
  • Activar/Desactivar: Bloquea o restaura el acceso de un usuario sin eliminarlo

14.3 Configuracion de IA

Configura el asistente de IA para respuestas automaticas:

  • Habilitar IA: Activa/desactiva respuestas automaticas
  • Modelo: Selecciona el modelo (gpt-4o-mini, gpt-4o, gpt-4-turbo)
  • Temperatura: 0 = respuestas precisas, 1 = respuestas creativas

La pantalla muestra indicadores de estado: si la IA esta habilitada en tu plan, si la clave API esta configurada, y cuantas consultas de IA has usado este mes.

16. Facturacion y Plan

Solo Admin

16.1 Tu Suscripcion

Muestra el plan actual, estado, ciclo de facturacion, precio y fechas.

16.2 Funciones de tu Plan

Lista de funciones habilitadas/deshabilitadas con indicadores visuales.

16.3 Uso Actual

Barras de progreso mostrando cuanto has consumido de cada limite (agentes, canales, conversaciones, mensajes, contactos, etc.).

16.4 Cambiar Plan

Desde "Cambiar Plan" puedes ver los planes disponibles con sus precios y funciones, y seleccionar uno nuevo.

16.5 Cancelar Suscripcion

Al cancelar, tienes un periodo de gracia de 7 dias donde puedes seguir usando la plataforma en modo lectura. Despues de ese periodo, el acceso se restringe.

17. Roles y Permisos

17.1 Administrador (org_admin)

Acceso completo a todas las funciones de la organizacion:

  • Configurar canales, equipo, facturacion
  • Crear y gestionar pipelines, etiquetas, marcas
  • Enviar campanas y configurar automatizaciones
  • Ver reportes y exportar datos
  • Gestionar comisiones de deals
  • Importar contactos

17.2 Supervisor

Gestiona agentes y conversaciones:

  • Ver todas las conversaciones (no solo las asignadas)
  • Asignar y transferir conversaciones
  • Crear y editar deals, contactos, articulos KB
  • Ver reportes (sin exportar)
  • No puede: configurar canales, equipo, facturacion, pipelines, campanas, automatizaciones, comisiones

17.3 Agente

Maneja las conversaciones que le son asignadas:

  • Ver y responder conversaciones asignadas
  • Cerrar conversaciones
  • Crear contactos y deals basicos
  • Ver articulos de KB (solo lectura)
  • No puede: ver conversaciones de otros, asignar/transferir, acceder a configuracion, reportes, campanas, automatizaciones
